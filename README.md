# Azure for Junior AI Engineers

A practical handbook on the Azure services you actually need when you start building LLM apps, RAG systems, agents, OCR pipelines and Python AI APIs.

I wrote it for people in their first year or two of AI engineering work who keep getting lost in the Azure portal and in old tutorials that use names Microsoft has since changed. Each service gets the same treatment: what it does, when to use it (and when not to), how to set it up in the portal, how to call it from Python, and what you will be billed for.

**[Read the PDF](./Azure-for-Junior-AI-Engineers.pdf)** (72 pages, A4)

## What's inside

- Cloud basics: subscriptions, resource groups, regions, quotas, and how your Python code signs in
- Microsoft Foundry, Foundry Models and Azure OpenAI
- Foundry Agent Service and Content Safety
- Document Intelligence for OCR and document extraction
- Azure AI Search, RAG from documents to answers, and testing answer quality
- Storage and databases: Blob Storage, PostgreSQL with pgvector, Cosmos DB
- Running your app: Container Apps, Container Registry, Azure Functions
- Managed identities, roles and Key Vault
- Monitoring with Azure Monitor and Application Insights
- Cost, quotas and habits that keep your bill small
- Four starter architectures: chat with your documents, an agent app, an OCR pipeline, a Python AI API
- A learning roadmap and a quick reference with packages, commands and common errors

## A note on accuracy

Cloud services change all the time. The guide was last reviewed on 13 October 2026, and every section links to the official Microsoft docs it is based on. If something matters for your project (prices, regional availability, preview status), check the linked page before relying on it.

If you find something that is out of date or wrong, please open an issue.
